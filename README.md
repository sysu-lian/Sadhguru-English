# Sadhguru-English · 萨古鲁英语高频词开源库

> **v0.1 首发：前 900 词 + 900 张 AI 配图，词图全配套，而且图随仓库发布——clone 下来就有图，不用再拉一次。**
> 全量 **3878 词**的英式音标 / 词性 / 中文释义也一起开源；配图按区间陆续补。

- **词**：3878 个从 Sadhguru 公开英文演讲语料中抽出的高频词，含英式音标（RP）、词性、中文释义，覆盖率 100%。
- **图**：前 900 词各一张 512×512 词卡插画，WebP q80 + JPEG q90 双格式，**900 / 900 无一缺失**。
- **净**：仓库就两样东西——`data/`（纯文本词表与例句）和 `images/`（900 张成品图），
  没有 CI、没有多余文档、没有出图脚本；只背词的话翻完这一页就够用了。

这套东西由 **学达单词**（<https://sle.chuanxi.fun/>）维护并开源：
词与图是公开的，站点上的发音、跟读判分与学习调度是另一层产品。
clone 走全部数据，clone 不出一个完整学习站；用得上的人顺手去站点练两关，是这套数据真正的用武之地。

词表语料取自公开演讲文本的**词频统计**（事实性数据），
不含任何演讲原文摘录、金句或语录的再分发——这一条是本仓库的硬红线，加数据只会更严，不会更松。

## Anki 牌组：Sadhguru-English Core 900

预打包的 `.apkg` 挂在 GitHub Release 上，下载后直接导入 Anki，不用先跑任何脚本。
**牌组不含发音音频**——音频为什么不随发布走，见下方「为什么牌组里没有音频」。

**牌组里有什么**

| 卡片类型                      | 笔记 / 卡数     | 正面                | 背面                              |
| ------------------------- | ----------- | ----------------- | ------------------------------- |
| `SE-Pic` 看图识词               | 900 笔记 / 900 卡 | 只有一张词卡插图         | 词形 + 音标 + 词性 + 中文释义   |
| `SE-Flash` 英→中 / 中→英         | 900 笔记 / 1800 卡 | 词 + 音标，反向是中文 | 中文释义 + 例句（英 / 中）              |
| `SE-Sent` 例句填空               | 900 笔记 / 900 卡 | 例句，目标词挖成 `____`   | 完整例句 + 中文 + 词形         |

- 合计 **2700 笔记 / 3600 张卡**，媒体 **900 个**（全部是 512×512 的 JPEG 词卡插画），包体 ≈ **46 MB**。
- **刻意不含音频**：音频一律不入库、不进 Release，需要发音请自行合成（见「不用自己打包」）。
- 900 条例句**全部自撰**，取景是乡村、厨房、田地这些日常场景，
  不会出现任何演讲原文或金句——维护方在出图与打包两侧各有一组断言死守这条线。

**为什么牌组里没有音频**

牌组只发图与文本，音频**既不入库也不进 Release**。原因是授权链：语音若走 edge-tts
（微软 Edge 浏览器「大声朗读」接口），微软在官方问答中明确表示**没有**书面许可录制并公开
再分发该功能生成的音频；要拿到明确授权需改用 Azure 官方语音服务。
既然我们无权对外授予这项再分发许可，就不把它打进发布物——
**音频改由使用者自行合成**，授权关系随之落在使用者与所用语音服务方之间，与本仓库无关。

> 想要带发音的牌组：用任意 TTS 合成 mp3（词一个文件、例句一个文件），再挂到 Anki 的
> 音频字段上即可（字段内容写成 `[sound:文件名.mp3]`）。**自己生成的音频请勿随本仓库一起再分发。**

**导入步骤**（桌面端 / AnkiDroid / AnkiMobile 通用）

1. Release 页下载 `Sadhguru-English-Core900.apkg`。
2. Anki 里 `文件 → 导入`，选中 apkg，牌组名保持 `Sadhguru-English Core 900`。
3. 库里若已有同名牌组，选「更新现有牌组」而不是新建，否则会冒出一批重复卡。
4. 新卡量建议从每天 20 张起步：3600 张对新用户偏多，容易第一次就劝退。

**不用自己打包**

Release 里的 `.apkg` 就是最终产物，导入即用。打包脚本属维护方工具链、不随本仓库发布，
但**牌组用的素材全部在仓库里**，想自建一套等价的卡片并不难：

| 卡片需要的字段 | 从哪拿                                    |
| ------- | -------------------------------------- |
| 词形 / 音标 / 词性 / 中释义 | `data/words-1-900.csv`                 |
| 例句（英 / 中）  | `data/examples-1-900.csv`                |
| 配图      | `images/<区间>/<序号>-<词>.jpg`（512×512）        |

用 Anki 手工建卡或用任意脚本（`genanki` 等）拼装都可以，字段对应关系就是上表。

## 这些图是怎么做出来的（流程说明）

出图链路跑在维护方本地，脚本不随仓库发布，但流程是公开的、可复刻的：

1. 逐词写画面设计（画什么、用哪个出镜形象、验收要点）——内部工作稿。
2. 按设计批量生成英文提示词，交给本地 **FLUX.1 [schnell]**（Draw Things，q8）以
   1080×1080 出源图，留出裁剪余量，再统一缩到 512×512。
3. 产出双格式：**WebP q80** 主档 + **JPEG q90** 兜底。
4. 出图前后各跑一遍断言：尺寸 / 双格式严格配对 / 无空白图 / 无文字残留 / 词表无演讲原文。

提示词长什么样可以直接看 `data/prompts-example.csv`（40 条样例）；
想要现成的图，`images/` 里 900 张已经躺在本仓库里了，什么都不用装。

## 与「学达单词」的关系（以及怎么给站点引流）

本仓库由 **学达单词**（<https://sle.chuanxi.fun/>）维护：
开源的是**词表 + 配图**这类公开语料与素材，**不含**学习站的调度算法、语音判分、用户数据等任何产品逻辑。

想把这份材料拿去小红书 / 公众号 / Anki 分享并顺手带站点？几条能直接用的规矩：

- **能拿出去**：`images/` 里的词卡插画（含你自己的排版）、`data/` 里的词表与音标。
- **不能拿出去**：站点的 UI 截图、交互录屏、用户数据与判分内容。
- **必须带的一句话**：图与词来自 Sadhguru-English（CC BY 4.0），由 学达单词 维护。
- **能放的引流话术**（示意，别照抄死）：
  词卡下面的小字写「完整发音和跟读判分在 [sle.chuanxi.fun](https://sle.chuanxi.fun/)」；
  分享 9 张图配一段「这是我从 3878 个高频词里挑的前 100 个，音标是英式 RP」，
  比堆参数更能让人点进来。
