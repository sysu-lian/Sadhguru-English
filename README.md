# Sadhguru-English

**3878 个从 Sadhguru 公开英文演讲文本中统计出的高频词**——带英式音标（RP）、词性、中文释义，按真实词频排序。第 1–2000 词各配一张 512×512 插画（共 2000 词），另附一份覆盖前 900 词的 Anki 牌组。

词表、例句、配图全部 **CC BY 4.0**，商用也行。

---

## 为什么值得用

- **词是真高频，不是拍脑袋选的**：从萨古鲁公开英文演讲语料做词频统计，按出现次数降序排列，先背最值钱的词。
- **一条链配齐**：词形 + 音标 + 词性 + 释义 + 例句 + 插图，不用东拼西凑。
- **开箱即背**：附一份覆盖前 900 词的 Anki 牌组，下载导入就能用；2000 张图就在仓库里，`git clone` 完就有，不用再拉一次。

## Anki 牌组

在 [Releases](https://github.com/sysu-lian/Sadhguru-English/releases) 页下载 `Sadhguru-English-Core900.apkg`，Anki 里 `文件 → 导入` 即可。

| 卡型 | 卡数 | 练什么 |
| --- | --- | --- |
| `SE-Pic` | 900 | 看图 → 词形 + 音标 + 释义 |
| `SE-Flash` | 1800 | 英 → 中 / 中 → 英 |
| `SE-Sent` | 900 | 例句挖空填空 |

- 媒体是 900 张 JPEG 插画，包体约 **46 MB**；新卡建议每天 20 张起步。
- **不含发音音频**：语音的再分发授权不够清楚（比如 Edge 的「大声朗读」接口就没有明示许可），所以音频不随发布走。想要发音，自己用任意 TTS 合成 mp3 挂上去即可——**但请勿随本仓库再分发**。
